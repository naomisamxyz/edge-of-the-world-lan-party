Characters

    
Turn a 2D character image into a rigged, animated, playable character in Unity

  


  

    Workflow
    Prepare the image
    Generate the model
    Prepare for Mixamo
    Rig and animate
    Import into Unity
    Replace the character
    Test and fix
  


  

  

    
Workflow

    
This workflow uses a single image to generate a 3D model, rigs that model for animation, and places it inside an existing Unity third-person controller.

    
Photoshop image → Meshy → MeshLab if needed → Mixamo → Unity

    
Each tool has a separate job: Photoshop prepares the source image, Meshy estimates a 3D form, MeshLab converts or simplifies the mesh when necessary, Mixamo adds a skeleton and animations, and Unity connects the finished character to the game.

  


  

  

    
Prepare the image

    
Begin with one clean, front-facing, full-body image. The generator has to infer everything it cannot see, so a clear silhouette produces a more usable model.


    
Create a clear source image

    
    
      
  1. Open the image in Photoshop and remove the background.
    2. 
      
  2. Use an A-pose or T-pose, with the arms held away from the torso and the legs separated.
    3. 
      
  3. Make sure the hands and feet are visible and that no part of the character is cropped.
    4. 
      
  4. Export the result as a PNG with a transparent or plain background.
    5. 
    

    
Character_Front.png

  


  

  

    
Generate the model

    
Meshy can estimate a 3D character from the prepared image. Because it only receives a front view, the sides and back are interpretations rather than exact reconstructions.


    
Image to 3D

    
    
      
  1. Open Meshy and choose Image to 3D.
    2. 
      
  2. Upload Character_Front.png.
    3. 
      
  3. Enable background removal or image enhancement if the source still needs cleanup.
    4. 
      
  4. Select an A-pose or T-pose if pose controls are available, then generate the model.
    5. 
      
  5. Rotate the result and inspect the arms, legs, hands, feet, sides, and back. Generate another version if important body parts are fused, missing, or badly distorted.
    6. 
    

    
See the Meshy Image-to-3D guide for the current controls.


    

      

        
Before downloading

        

          
Plan limits
Credit, model, and download limits can change. Check the current free-plan documentation before choosing a model version.

          
License
Check whether the generated model requires attribution and record the license information with your project files.

          
Geometry
Choose the simplest model that preserves the character. An unnecessarily dense mesh will be slower to edit, animate, and render.

        

      

    

  


  

  

    
Prepare for Mixamo

    
Mixamo accepts FBX, OBJ, and ZIP files, but not GLB. Download an FBX when Meshy provides one; otherwise convert the model before uploading it.


    
Convert a GLB with MeshLab

    
    
      
  1. Open the GLB in MeshLab.
    2. 
      
  2. Choose File → Export Mesh As.
    3. 
      
  3. Export the model as Character_For_Mixamo.obj.
    4. 
      
  4. Place the OBJ, its MTL file, and its textures together inside a ZIP archive.
    5. 
    

    
Character_For_Mixamo.zip
├── Character_For_Mixamo.obj
├── Character_For_Mixamo.mtl
└── Textures/

    
If textures disappear during conversion, you can still rig the untextured geometry and reconnect the original Meshy textures later in Unity. MeshLab can also simplify an overly dense mesh before it is rigged.

    
See Adobe's Mixamo rigging and animation guide for supported upload formats and current requirements.

  


  

  

    
Rig and animate

    
Rigging adds a skeleton to the mesh. Mixamo uses that skeleton to bend the character and apply reusable humanoid animations.


    
Create the skeleton in Mixamo

    
    
      
  1. Open Mixamo and click Upload Character.
    2. 
      
  2. Upload the Meshy FBX or the ZIP created with MeshLab.
    3. 
      
  3. Place the markers on the chin, wrists, elbows, knees, and groin.
    4. 
      
  4. Let Mixamo create the skeleton, then test the result with a walking animation.
    5. 
      
  5. If the knees or elbows bend incorrectly, upload the character again and reposition the markers.
    6. 
    


    

      

        
Download settings

        

          
Base character
Format: FBX for Unity
Skin: With Skin
Frames Per Second: 30

          
Additional animations
Download separate animation files Without Skin. Enable In Place for walking and running when Unity's controller will move the character through the scene.

        

      

    

  


  

  

    
Import into Unity

    
Keep the character model, materials, textures, and animations together in a clearly named project folder.

    
Assets/Characters/MyCharacter/


    
Configure the Humanoid Avatar

    
    
      
  1. Drag the FBX and its texture files into the character folder in Unity's Project window.
    2. 
      
  2. Select the FBX and open the Rig tab in the Inspector.
    3. 
      
  3. Set Animation Type to Humanoid.
    4. 
      
  4. Set Avatar Definition to Create From This Model.
    5. 
      
  5. Click Apply, then Configure.
    6. 
      
  6. Confirm that Unity recognizes the main body bones. Use Enforce T-Pose if necessary, then save the Avatar configuration.
    7. 
    

    
The Humanoid Avatar lets Unity retarget compatible animations to this character. See the Unity Humanoid Avatar documentation for details.

  


  

  

    
Replace the third-person character

    
Keep the working player root. It already contains the movement, input, collider, camera target, and other gameplay components. Replace only the visible character model beneath it.


    
Preserve the working controller

    
    
      
  1. Duplicate the working player before making changes.
    2. 
      
  2. Drag the newly rigged character beneath the duplicated player root.
    3. 
      
  3. Disable the old visible character instead of deleting the player root.
    4. 
    

    
Player_CustomCharacter
├── CameraTarget
├── GroundCheck
├── OldCharacter
└── Character_Rigged


    
Align the model

    
    
      
  1. Set the new character's local Position and Rotation to 0, 0, 0, and its local Scale to 1, 1, 1.
    2. 
      
  2. If the character faces backward, rotate only the visible character model 180 degrees on Y.
    3. 
      
  3. Adjust the model's vertical position until its feet meet the ground.
    4. 
      
  4. Resize and reposition the Character Controller capsule so it fits the new body.
    5. 
    


    
Configure the Animator

    

      

        

          
Controller
Use the existing Third Person Animator Controller.

          
Avatar
Assign the Avatar generated from Character_Rigged.

          
Apply Root Motion
Leave this off when the player movement script controls the character's position.

          
Animator reference
If the movement script exposes an Animator field, assign the new character's Animator component to it.

        

      

    

  


  

  

    
Test and fix


    
Missing textures

    
    
      
  1. If the character appears gray, create a new Unity material.
    2. 
      
  2. Choose the shader used by the project: Standard for the Built-In Render Pipeline, URP Lit for URP, or HDRP Lit for HDRP.
    3. 
      
  3. Assign the original Meshy texture images to the material.
    4. 
      
  4. Apply the material to the character mesh.
    5. 
    


    
Play Mode test

    
Enter Play Mode and test idle, walking, running, turning, jumping, landing, camera movement, and collisions. Watch the feet, knees, elbows, and ground contact closely.
