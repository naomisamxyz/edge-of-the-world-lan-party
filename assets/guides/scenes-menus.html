What is a scene?

    
A Scene is a container for one part of a Unity project. It holds the GameObjects, cameras, lights, interfaces and other content needed for that part of the game.

    
Different scenes might contain:

    
    
      
  • A main menu
    • 
      
  • A game level
    • 
      
  • A building interior
    • 
      
  • A character-selection screen
    • 
      
  • A game-over screen
    • 
      
  • A credits screen
    • 
    

    
Loading a scene normally closes the current scene and opens another one.

    
Scenes help keep a project organized. Instead of placing the entire game inside one large scene, different locations and activities can exist in separate files.

  


  

    
What is a menu?

    
A menu is an interface that allows the player to make choices.

    
A menu can include:

    
    
      
  • Start Game
    • 
      
  • Continue
    • 
      
  • Restart
    • 
      
  • Level selection
    • 
      
  • Inventory
    • 
      
  • Settings
    • 
      
  • Accessibility options
    • 
      
  • Pause and resume
    • 
      
  • Return to the main menu
    • 
      
  • Quit the game
    • 
    

    
Menus are usually created with a Canvas, Buttons and TextMeshPro text.

    
A main menu is often placed in its own scene. A pause menu, inventory or settings menu can be a Canvas panel inside the gameplay scene.

  


  

    
How scenes and menus work together

    
A scene holds the content. A menu gives the player a way to navigate or interact with that content.

      │ Return to Menu Button

Input System setup

    
This project uses Unity’s new Input System, not the old Input Manager.


    
Install the Input System

    
    
      
  1. Open Window → Package Manager.
    2. 
      
  2. Select Unity Registry.
    3. 
      
  3. Find Input System.
    4. 
      
  4. Select Install.
    5. 
    


    
Enable the Input System

    
    
      
  1. Open Edit → Project Settings.
    2. 
      
  2. Select Player.
    3. 
      
  3. Find Active Input Handling.
    4. 
      
  4. Select Input System Package (New).
    5. 
    

    
Unity may ask to restart the Editor.


    
Configure UI input

    
Buttons require an EventSystem.

    
When Unity creates a Canvas and Button, it normally creates an EventSystem automatically.

    
    
      
  1. Select EventSystem in the Hierarchy.
    2. 
      
  2. Find the old Standalone Input Module.
    3. 
      
  3. Select Replace with InputSystemUIInputModule.
    4. 
    

    
If that option does not appear:

    
    
      
  1. Remove the Standalone Input Module.
    2. 
      
  2. Select Add Component.
    3. 
      
  3. Add Input System UI Input Module.
    4. 
    

    
The scene should contain:

    
EventSystem
└── Input System UI Input Module

    
Do not use the old Standalone Input Module.

  


  

    
Tutorial: move between a menu and a game

    
This tutorial creates:

    
    
      
  • A MainMenu scene
    • 
      
  • A Game scene
    • 
      
  • A button that starts the game
    • 
      
  • A button that returns to the menu
    • 
    

    
Choose either C# or Visual Scripting. Do not use both on the same button.


    
Create the main menu scene

    
    
      
  1. Select File → New Scene.
    2. 
      
  2. Choose a basic scene.
    3. 
      
  3. Save it as MainMenu.
    4. 
      
  4. Select GameObject → UI → Canvas.
    5. 
      
  5. Add Text - TextMeshPro.
    6. 
      
  6. Change the text to the name of the game.
    7. 
      
  7. Add Button - TextMeshPro.
    8. 
      
  8. Change its text to Start Game.
    9. 
    

    
If Unity asks, select Import TMP Essentials.

    
Check that the scene’s EventSystem uses Input System UI Input Module.


    
Create the game scene

    
    
      
  1. Select File → New Scene.
    2. 
      
  2. Save it as Game.
    3. 
      
  3. Add a simple object, environment or player.
    4. 
      
  4. Add a Canvas.
    5. 
      
  5. Add a TextMeshPro Button.
    6. 
      
  6. Change its text to Return to Menu.
    7. 
      
  7. Check that the EventSystem uses Input System UI Input Module.
    8. 
    


    
Add the scenes to Build Settings

    
Unity 2022 uses Build Settings.

    
    
      
  1. Open MainMenu.
    2. 
      
  2. Select File → Build Settings.
    3. 
      
  3. Select Add Open Scenes.
    4. 
      
  4. Open Game.
    5. 
      
  5. Return to File → Build Settings.
    6. 
      
  6. Select Add Open Scenes again.
    7. 
    

    
The Scenes In Build list should contain:

    
0  MainMenu
1  Game

    
Make sure both scenes have checkmarks.

    
Scene 0 is normally the first scene Unity opens in a finished build.


    
Option A: C#

    
Create the navigation script

    
Create a C# script named MenuNavigation:

    
using UnityEngine;
using UnityEngine.SceneManagement;

public class MenuNavigation : MonoBehaviour
{
    public void StartGame()
    {
        // Restore normal game time in case the game was previously paused.
        Time.timeScale = 1f;

        // Close the current scene and load the Game scene.
        SceneManager.LoadScene("Game");
    }

    public void ReturnToMenu()
    {
        // Restore normal time before changing scenes.
        Time.timeScale = 1f;

        // Close the current scene and load the MainMenu scene.
        SceneManager.LoadScene("MainMenu");
    }
}

    
The names inside quotation marks must match the scene filenames.

    
Connect the Start button

    
Open MainMenu:

    
    
      
  1. Create an empty GameObject.
    2. 
      
  2. Name it MenuNavigation.
    3. 
      
  3. Add the MenuNavigation script.
    4. 
      
  4. Select the Start Game button.
    5. 
      
  5. Find On Click ().
    6. 
      
  6. Press +.
    7. 
      
  7. Drag the MenuNavigation GameObject into the field.
    8. 
      
  8. Select MenuNavigation → StartGame().
    9. 
    

    
Connect the Return button

    
Open Game:

    
    
      
  1. Create an empty GameObject.
    2. 
      
  2. Name it MenuNavigation.
    3. 
      
  3. Add the same script.
    4. 
      
  4. Select the Return to Menu button.
    5. 
      
  5. Press + under On Click ().
    6. 
      
  6. Drag MenuNavigation into the field.
    7. 
      
  7. Select MenuNavigation → ReturnToMenu().
    8. 
    

    
Enter Play Mode from MainMenu and test both buttons.

Pause menu

    
The pause menu should use an Input Action rather than the old Input.GetKeyDown system.


    
Create the Input Actions asset

    
    
      
  1. In the Project window, right-click.
    2. 
      
  2. Select Create → Input Actions.
    3. 
      
  3. Name the asset MenuControls.
    4. 
      
  4. Double-click it to open the Input Actions editor.
    5. 
      
  5. Create an Action Map named UI.
    6. 
      
  6. Create an Action named Pause.
    7. 
      
  7. Set its Action Type to Button.
    8. 
      
  8. Add a binding.
    9. 
      
  9. Set the binding path to Keyboard → Escape.
    10. 
      
  10. Optional: add another binding for a controller, Gamepad → Start.
    11. 
      
  11. Select Save Asset.
    12. 
    

    
The same Pause action can now respond to either Escape or a controller’s Start button.


    
Create the pause panel

    
A pause menu normally remains inside the Game scene.

    
    
      
  1. Add a Panel to the gameplay Canvas.
    2. 
      
  2. Name it PauseMenu.
    3. 
      
  3. Add a title and a Resume button.
    4. 
      
  4. Disable PauseMenu in the Inspector.
    5. 
    

    
The panel begins hidden.


    
Option A: C#

    
Create a script named PauseMenuController:

    
using UnityEngine;
using UnityEngine.InputSystem;

public class PauseMenuController : MonoBehaviour
{
    // Drag the Pause action from MenuControls into this field.
    public InputActionReference pauseAction;

    // Drag the PauseMenu panel into this field.
    public GameObject pauseMenuPanel;

    void OnEnable()
    {
        // Begin listening for the Pause action.
        pauseAction.action.Enable();
    }

    void OnDisable()
    {
        // Stop listening when this component is disabled.
        pauseAction.action.Disable();
    }

    void Update()
    {
        // Check whether the Pause action was pressed this frame.
        if (pauseAction.action.WasPressedThisFrame())
        {
            TogglePause();
        }
    }

    public void TogglePause()
    {
        // Reverse the panel's current visibility.
        bool isPaused = !pauseMenuPanel.activeSelf;

        // Show or hide the pause menu.
        pauseMenuPanel.SetActive(isPaused);

        // Stop time when paused and restore it when resumed.
        Time.timeScale = isPaused ? 0f : 1f;
    }

    public void ResumeGame()
    {
        // Hide the pause menu.
        pauseMenuPanel.SetActive(false);

        // Resume normal game time.
        Time.timeScale = 1f;
    }
}

    
Connect the script

    
    
      
  1. Create an empty GameObject.
    2. 
      
  2. Name it PauseController.
    3. 
      
  3. Add the PauseMenuController script.
    4. 
      
  4. Drag the PauseMenu panel into Pause Menu Panel.
    5. 
      
  5. Drag the Pause action from MenuControls into Pause Action.
    6. 
      
  6. Connect the Resume button to PauseMenuController → ResumeGame().
    7. 
    


    
Option B: Visual Scripting

    
Prepare Visual Scripting for the Input System

    
After installing the Input System:

    
    
      
  1. Open Edit → Project Settings.
    2. 
      
  2. Select Visual Scripting.
    3. 
      
  3. Select Regenerate Nodes.
    4. 
    

    
This makes Input System nodes available in Visual Scripting.

    
Also check that the project has an Input System settings asset: in Edit → Project Settings → Input System Package, select Create Settings Asset if the project does not have one yet.

    
Create the pause graph

    
Visual Scripting reads input actions from a Player Input component. Add the Player Input component before you create the graph.

    
    
      
  1. Create an empty GameObject named PauseController.
    2. 
      
  2. Add a Player Input component.
    3. 
      
  3. Drag MenuControls into its Actions field and set Default Map to UI.
    4. 
      
  4. Add a Script Machine.
    5. 
      
  5. Create a new graph.
    6. 
      
  6. Add an On Input System Event Button node.
    7. 
      
  7. Select the Pause action in its Input Action list.
    8. 
      
  8. Set its Input Action Change Type to On Pressed.
    9. 
      
  9. Connect it to the pause logic:
        
    On Input System Event Button: Pause
      │
      ▼
Get Active: PauseMenu
      │
      ▼
Not
      │
      ▼
Set Active: PauseMenu
    
      
    10. 
    

    
Also use the result of Not to choose the time scale:

    
PauseMenu Active = True  ───▶ Set Time Scale: 0
PauseMenu Active = False ───▶ Set Time Scale: 1

    
The Resume button can use:

    
On Button Click
      │
      ├──▶ Set Active: PauseMenu = False
      │
      └──▶ Set Time Scale = 1

    
Use either the C# pause system or the Visual Scripting pause system—not both.

  


  

    
What scenes can do

    
    
      
  • Separate levels and locations
    • 
      
  • Organize menus and gameplay
    • 
      
  • Load new parts of the game
    • 
      
  • Restart a level
    • 
      
  • Separate lighting and environments
    • 
      
  • Create title, game-over and credits screens
    • 
      
  • Load additional content alongside the current scene
    • 
    

    
Single loading

    
LoadSceneMode.Single

    
Closes the current scene and loads the new one.

    
Additive loading

    
LoadSceneMode.Additive

    
Loads another scene without closing the current scene.

    
Use Single for the beginner menu tutorial.

Common problems


    
The button does nothing

    
Check that:

    
    
      
  • An EventSystem exists.
    • 
      
  • The EventSystem uses Input System UI Input Module.
    • 
      
  • The old Standalone Input Module was removed.
    • 
      
  • The Button is inside a Canvas.
    • 
      
  • The Button’s Interactable option is enabled.
    • 
      
  • The Button’s On Click () event is connected.
    • 
      
  • The Script Machine contains the correct graph.
    • 
    


    
Unity cannot load the scene

    
Check that:

    
    
      
  • The scene was added to File → Build Settings.
    • 
      
  • The scene has a checkmark in Scenes In Build.
    • 
      
  • The scene name matches the script or graph.
    • 
      
  • The name does not include .unity.
    • 
    

    
Correct:

    
SceneManager.LoadScene("Game");

    
Incorrect:

    
SceneManager.LoadScene("Game.unity");


    
Input System nodes are missing

    
    
      
  1. Confirm that the Input System package is installed.
    2. 
      
  2. Set Active Input Handling to Input System Package (New).
    3. 
      
  3. Open Project Settings → Visual Scripting.
    4. 
      
  4. Select Regenerate Nodes.
    5. 
    

    
If the Pause action does not appear in the node’s Input Action list, check that the same GameObject has a Player Input component with MenuControls assigned.


    
The game remains paused

    
Before loading or restarting gameplay, restore:

    
// Restore normal time.
Time.timeScale = 1f;

  


  

    
Best practices

    
    
      
  • Give scenes short, clear names.
    • 
      
  • Add every loadable scene to Build Settings.
    • 
      
  • Keep MainMenu first in the Scenes In Build list.
    • 
      
  • Use Input System UI Input Module on every EventSystem.
    • 
      
  • Use Input Actions instead of hard-coding keyboard checks.
    • 
      
  • Add keyboard and controller bindings to the same action.
    • 
      
  • Use a separate scene for the main menu.
    • 
      
  • Use Canvas panels for pause, settings and inventory menus.
    • 
      
  • Test every button in Play Mode.
    • 
      
  • Use either C# or Visual Scripting for an action—not both.
    • 
      
  • Remember that Single scene loading destroys the previous scene’s GameObjects.
    • 
      
  • Use state tracking, DontDestroyOnLoad or a save system when information must continue between scenes.
