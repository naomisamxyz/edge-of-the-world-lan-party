Terrain Tools

    
Terrain Tools is Unity's package for sculpting landscape. It adds extra brushes — smoothing, stamping, noise, erosion — on top of Unity's built-in Terrain object, which already handles height, ground textures, trees, and grass.


    
Set up

    
    
      
  1. Install it if it's not already in the project: Window → Package Manager → Unity Registry → Terrain Tools → Install.
    2. 
      
  2. Create a terrain: GameObject → 3D Object → Terrain. This adds a large flat plane.
    3. 
      
  3. Select it, then open the Terrain Settings tab first (the gear icon) and set its Width/Length/Height to match your scene's scale before sculpting — resizing later can distort what you've already sculpted.
    4. 
    


    

      

        
Core tools

        

          
Raise/Lower Terrain
push the ground up or down with a brush. Your main sculpting tool.

          
Smooth Height
blurs out sharp bumps and hard edges left by other brushes.

          
Stamp Terrain
stamps a brush shape at full height in one click — fast for hills or craters.

          
Set Height
flattens an area to an exact height. Use it for building foundations, roads, or a level water line.

          
Paint Texture
blends multiple ground textures — grass, rock, dirt — across the surface.

          
Paint Trees
scatters tree prefabs across the terrain by painting.

          
Paint Details
scatters small detail objects — grass, rocks — as lightweight billboards or meshes.

        

      

    


    

      

        
Additional tools, from the Terrain Tools package

        

          
Noise
generates natural-looking bumps and variation from a procedural pattern, instead of freehand sculpting every detail by hand.

          
Erosion
Hydraulic, Thermal, and Wind variants simulate water, gravity, or wind wearing the terrain down over time, for a weathered, natural look.

          
Terrace
carves the terrain into stepped levels — useful for canyons, rice paddies, or any stepped landscape.

          
Contrast
sharpens or softens the height differences across the whole terrain at once.

          
Bridge
connects two points across a gap with a ramp or path, so you don't have to sculpt the connection by hand.

          
Mesh Stamp
stamps the shape of a chosen 3D mesh into the terrain's height — sculpting with a model instead of a brush.

          
Clone Brush
copies terrain height from one area and paints it elsewhere, like Stamp but sourced from existing terrain rather than a preset shape.

          
Pinch / Smudge / Twist
smaller detail brushes: pinch sharpens a ridge inward, smudge drags height around like wet clay, twist spins it into a spiral.

          
Transform
moves, rotates, or scales terrain data that's already there, instead of painting new height.

        

      

    


    
A basic first pass

    
    
      
  1. Block out the landscape with Raise/Lower and Stamp, then pass over it with Smooth to soften hard edges.
    2. 
      
  2. Add ground textures: open Paint Texture, click Edit Terrain Layers → Create Layer, and choose an Albedo texture for each material (grass, dirt, rock).
    3. 
      
  3. Add trees and grass: add prefabs to the Paint Trees and Paint Details lists first, then paint them on like a texture.
    4. 
    

  


  

  

    
Importing assets

    
Best practice for bringing a static (non-animated) 3D model — a prop, a rock, a piece of architecture — into the project cleanly.


    

      

        
Free 3D model libraries

        

          
Poly Haven
high-quality realistic models, textures, and HDRIs. All assets are CC0 and can be used without attribution.

          
Kenney
game-ready 3D asset packs in a consistent, stylized low-poly aesthetic. Check the license shown on each download page.

          
Quaternius
free stylized asset packs for games, including environments, characters, props, and animations.

          
Sketchfab
a large collection of downloadable models from many creators. Licenses vary, so check whether attribution and commercial use are allowed before downloading.

          
Free3D
free models in many categories and file formats. Check the license attached to each model before using it.

          
Thingiverse
a large library of community-made models, primarily designed for 3D printing. Licenses vary, and models may need optimization before use in Unity.

          
TurboSquid
free models ranging from simple props to detailed realistic assets. Check the model's license, file format, and polygon count before downloading.

        

      

    

    


    
File type, size and detail

    
    
      
  1. Unity can reliably import .fbx and .obj files.
    2. 
      
  2. For .glb and .gltf files, use MeshLab to convert them.
    3. 
      
  3. Also check the download size, texture resolution, and polygon or triangle count. A model containing hundreds of thousands or millions of polygons, or several 4K/8K textures, can make Unity slow even when the download itself looks small. Choose the simplest version that still looks good at the size it will appear in the game.
    4. 
    

    


    

      

        
Import settings to check

        

          
Rig → Animation Type
set to None. A non-animated prop doesn't need a rig, and skipping it avoids Unity guessing at a skeleton and speeds up import.

          
Model → Scale Factor
confirm it results in 1 Unity unit = 1 meter. A prop that imports tiny or huge usually means the Scale Factor needs adjusting here, not in the Transform.

          
Model → Read/Write Enabled
leave off unless a script needs to read the mesh at runtime — on costs extra memory for no benefit on a static prop.

          
Model → Generate Colliders
only turn on if the object needs physics collisions. Leave it off for purely decorative props.

          
Materials → Location
use Extract Materials... to get real, editable material assets instead of ones embedded in the model file.

        

      

    


    
After importing

    
    
      
  1. Bring the files in by dragging them into Unity's Project window, not the OS file browser — that keeps textures and .meta files correctly linked (see Assets and naming).
    2. 
      
  2. If a GameObject will never move, rotate, or change scale while the game is running, select it in the Hierarchy and enable Static at the top-right of the Inspector. This tells Unity that the object can be included in optimizations such as static batching and baked lighting. Do not mark objects Static if they need to move during play.
    3. 
      
  3. If the material renders bright pink, its shader isn't URP-compatible yet — see URP shaders to fix it.
    4.
