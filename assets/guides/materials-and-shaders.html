Materials

    
A material tells Unity how a surface should look — its color, texture, roughness, and which shader draws it. Every mesh needs at least one material, or it renders in Unity's default pink/magenta error shader.


    
Create and assign one

    
    
      
  1. In the Project window: right-click → Create → Material.
    2. 
      
  2. Name it, then select it — the Inspector shows its shader and properties.
    3. 
      
  3. Drag it onto a mesh in the Scene view or the Hierarchy to assign it.
    4. 
    

  


  

  

    
URP shaders

    
Every material uses a shader — the small program that decides how light interacts with its surface. URP ships a handful of ready-made ones, so you rarely need to write your own.

    

      

        
Built-in URP shaders

        

          
Lit
the default. Supports lighting, normal maps, and metallic/smoothness. Use it for most props and characters.

          
Simple Lit
a cheaper lit shader with simpler lighting math. Use it for mobile or low-end targets.

          
Unlit
ignores scene lighting entirely — flat color or texture only. Use it for UI, skyboxes, or stylized flat looks.

          
Baked Lit
a lit shader for objects using only baked, not real-time, lighting. Cheaper than Lit.

        

      

    

  


  

  

    
Skybox materials

    
A skybox material is a special material Unity renders behind everything else in the scene, at infinite distance — it's what gives an empty scene a sky instead of a flat background color.

    

      

        
Skybox types

        

          
Procedural
a simple generated sky and sun, controlled by sliders. No image needed — good for a quick placeholder.

          
Panoramic
uses a single 360° HDRI image. The easiest way to get a real photographed or rendered sky.

          
6 Sided
uses six separate images, one per face of a cube around the camera.

          
Cubemap
uses a single Cubemap texture asset instead of six loose images.

        

      

    

    
Set one

    
    
      
  1. Create a material and set its shader to one under Skybox (for example Skybox/Panoramic), then assign your HDRI image to it.
    2. 
      
  2. Open Window → Rendering → Lighting, go to the Environment tab, and drag the material into the Skybox Material field.
    3. 
    

  


  

  

    
Shader Graph

    
Shader Graph is Unity's visual shader editor. Instead of writing shader code, you connect nodes — a texture, a color, some math — to a set of outputs, and Unity generates the shader for you.

    
It's worth it once a stock URP shader can't do what you want: stylized effects like toon shading, a dissolve, water, or a glow all start here, and you can see and tweak the result without knowing HLSL.


    
Your first Shader Graph

    
    
      
  1. In the Project window: right-click → Create → Shader Graph → URP → Lit Shader Graph.
    2. 
      
  2. Double-click it to open the Shader Graph window.
    3. 
      
  3. Drag in a Color node and connect it to Base Color on the Fragment output.
    4. 
      
  4. Click Save Asset (top-left) to compile it.
    5. 
      
  5. Create a material, set its shader to your new Shader Graph asset, then assign the material to a mesh like any other.
    6. 
    

  


  

  

    
Wobble Shader

    
This shader changes the position of the mesh's vertices over time. Different parts of the object move by different amounts, creating a wave instead of moving the whole object.


    
1. Create the Shader Graph

    
    
      
  1. Create → Shader Graph → URP → Lit Shader Graph.
    2. 
      
  2. Name it Wobble.
    3. 
      
  3. Create three Float properties:
        
      
          
    • Speed = 2
      • 
          
    • Frequency = 5
      • 
          
    • Amount = 0.1
      • 
        
    
      
    4. 
    


    
2. Find each vertex's height

    
Position (Object) → Split → G

    
    
      
  • Position gives us the position of every vertex.
    • 
      
  • Split separates X, Y and Z.
    • 
      
  • G is the Y value, the vertex's height.
    • 
    


    
3. Create the wave

    
Build:

    
Position Y → Multiply ← Frequency
                   ↓
                  Add ← Time × Speed
                   ↓
                  Sine
                   ↓
                Multiply ← Amount

    
This calculates: sin(Time × Speed + PositionY × Frequency) × Amount

    
What each part does:

    
    
      
  • Time makes it animate.
    • 
      
  • Speed controls how fast.
    • 
      
  • Position Y makes vertices at different heights move differently.
    • 
      
  • Frequency controls how many waves appear across the mesh.
    • 
      
  • Sine creates smooth back-and-forth movement.
    • 
      
  • Amount controls how far the vertices move.
    • 
    


    
4. Turn it into movement

    
Use Combine:

    
R = wobble
G = 0
B = 0

    
This means the wobble only moves vertices along X. Then:

    
Position (Object) ────────┐
                          Add → Vertex Position
Wobble → Combine RGB ─────┘

    
We take each vertex's original position and add the wobble to it.


    
Full graph

    
Position → Split → Y → × Frequency ─┐
                                    ↓
Time → × Speed ──────────────────→ Add
                                    ↓
                                   Sine
                                    ↓
                                × Amount
                                    ↓
                                 Combine
                                    ↓
Position ───────────────────────→ Add
                                    ↓
                              Vertex Position


    
Important: the model needs enough vertices/subdivisions. Shader Graph can move existing vertices, but it cannot bend areas where there are no vertices.

  


  

  

    
Make an Object Bounce

    
A Physics Material controls how a Collider behaves on impact — friction and bounciness — separate from the rendering material on its Mesh Renderer.


    
1. Set up the object

    
Select the object and add:

    
    
      
  • Rigidbody
    • 
      
  • Collider appropriate for its shape
    • 
    

    
On the Rigidbody:

    
    
      
  • Use Gravity: On
    • 
      
  • Linear Damping: 0
    • 
      
  • Angular Damping: 0
    • 
    


    
2. Create a Physics Material

    
    
      
  1. In the Project window: right-click → Create → Physics Material.
    2. 
      
  2. Name it Bouncy.
    3. 
    

    

      

        
Settings

        

          
Dynamic Friction
0

          
Static Friction
0

          
Bounciness
0.8

          
Friction Combine
Average

          
Bounce Combine
Maximum

        

      

    


    
3. Apply the material

    
    
      
  1. Select the bouncing object's Collider.
    2. 
      
  2. Drag the Bouncy Physics Material into its Material field.
    3. 
    

    
A Physics Material goes on the Collider, not the Mesh Renderer.


    
4. Set up the ground

    
    
      
  • Make sure the ground has a Collider.
    • 
      
  • It does not need a Rigidbody.
    • 
    


    
5. Test

    
Move the object above the ground and press Play. Gravity pulls it down, the Collider detects the impact, and the Physics Material determines how much it bounces back.

    
With Bounciness = 0.8, each bounce should be smaller than the previous one until the object eventually settles.
