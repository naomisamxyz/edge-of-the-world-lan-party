Cinemachine

    
Cinemachine controls Unity’s Main Camera through lightweight Virtual Cameras. It can follow a player, frame a character, blend between viewpoints and create cinematic shots without manually animating the Main Camera.


    
Setup

    
Install these packages through Window → Package Manager:

    
    
      
  • Cinemachine
    • 
      
  • Timeline
    • 
      
  • Recorder
    • 
    

    
Create a Virtual Camera:

    
GameObject → Cinemachine → Virtual Camera

    
Cinemachine automatically adds a Cinemachine Brain to the Main Camera.


    
First- or Third-Person Controller

    
Select the Virtual Camera and assign the controller’s camera target — often named CinemachineCameraTarget or PlayerCameraRoot — to:

    

      

        

          
Follow
the object the camera moves with.

          
Look At
the object the camera points toward.

        

      

    

    
For a third-person controller, use Third Person Follow or a FreeLook Camera. For first-person, position the camera target near the character’s head and use minimal damping.

    
Do not delete the controller’s camera target: Cinemachine follows it while the controller handles player input.

  


  

  

    
Timeline

    
Timeline can switch and blend between several Virtual Cameras.

    
    
      
  1. Create an empty GameObject named Cutscene.
    2. 
      
  2. Open Window → Sequencing → Timeline.
    3. 
      
  3. Create a Timeline asset.
    4. 
      
  4. Add a Cinemachine Track.
    5. 
      
  5. Bind it to the Main Camera’s Cinemachine Brain.
    6. 
      
  6. Add Virtual Cameras as Cinemachine Shot clips.
    7. 
      
  7. Arrange and overlap the clips to create cuts and blends.
    8. 
    

    
Timeline controls which Virtual Camera is active; Cinemachine controls how each shot moves and frames its subject.

  


  

  

    
Recorder

    
Recorder exports the finished sequence as a video.

    
    
      
  1. Open Window → General → Recorder → Recorder Window.
    2. 
      
  2. Add a Movie Clip recorder.
    3. 
      
  3. Set the source to Game View.
    4. 
      
  4. Choose the resolution, frame rate and output location.
    5. 
      
  5. Select Start Recording.
    6. 
      
  6. Play the Timeline.
    7. 
    

    
Use the player camera for gameplay, Cinemachine cameras for composition, Timeline for editing shots, and Recorder for exporting the result.
