UI foundations

    
A user interface places information and controls on top of the game world: titles, instructions, buttons, health bars, inventories, dialogue, and menus. Unity UI elements live inside a Canvas and use a Rect Transform instead of a regular Transform.


    
Create a Canvas

    
    
      
  1. In the Hierarchy, right-click and choose a component from the UI menu, such as UI → Image or UI → Button - TextMeshPro.
    2. 
      
  2. If the scene does not contain a Canvas, Unity creates one and places the new UI object inside it.
    3. 
      
  3. Unity also creates an EventSystem when needed. It receives mouse, keyboard, touch, and controller events for interactive UI components.
    4. 
      
  4. Switch the Scene view to 2D and keep the Game view visible while arranging the interface.
    5. 
    


    

      

        
Common UI components

        

          
Canvas
The container that defines where and how the interface is rendered.

          
Rect Transform
Controls a UI element's position, size, anchors, pivot, scale, and rotation relative to its parent.

          
Image
Displays a sprite. Use it for backgrounds, icons, frames, progress fills, and other graphic elements.

          
TextMeshPro
Displays sharp, controllable text using a TextMesh Pro font asset.

          
Button
Responds to a click or submit action and can call one or more functions through its On Click event.

          
Slider
Lets the player choose a value within a range and is also useful as the structure for volume or progress controls.

          
Scroll View
Places larger content inside a movable viewport for inventories, credits, menus, or long text.

          
Mask
Hides parts of child elements that extend beyond a defined visible area.

        

      

    

    
See Unity Learn's UI Components tutorial for more examples.

  


  

  

    
Screen size and anchors

    
A UI that looks correct at one resolution can drift, stretch, or leave the screen at another. Test the layout at multiple aspect ratios and use anchors to describe which part of the parent each element should stay attached to.


    
Set up the Canvas Scaler

    
    
      
  1. Select the Canvas and find its Canvas Scaler component.
    2. 
      
  2. Set UI Scale Mode to Scale With Screen Size.
    3. 
      
  3. Set Reference Resolution to the resolution used to design the interface. For class projects, begin with 1920 × 1080.
    4. 
      
  4. Use Screen Match Mode: Match Width Or Height. Start with Match near the middle, then adjust it according to whether preserving the horizontal or vertical layout matters more.
    5. 
      
  5. Use the Game view resolution menu to test 16:9 and several narrower and wider window shapes.
    6. 
    


    

      

        
Anchors and pivots

        

          
Anchor
The point or area on the parent that the UI element follows when the parent changes size. A settings button in the top-right corner should be anchored to the top-right, not the center.

          
Stretch anchors
Attach opposite edges of an element to opposite edges of its parent. Use them when a panel or background should grow and shrink with the available space.

          
Pivot
The point inside the element used for positioning, scaling, and rotation. A confusing rotation or resize often means the pivot is in the wrong place.

          
Anchor Presets
Open the square preset control in the Rect Transform. Choose a corner, edge, center, or stretch preset instead of positioning every anchor manually.

        

      

    

    
After setting an anchor, resize the Game view and confirm that the element stays attached to the intended corner, edge, or region. Follow Unity Learn's Manage screen size and anchors tutorial for a guided exercise.

  


  

  

    
TextMesh Pro font assets

    
TextMesh Pro does not use a font file directly. It uses a Font Asset, which stores character data and a texture atlas containing the glyphs that Unity renders.


    
Create a font asset

    
    
      
  1. Create a folder such as Assets/Fonts/ and place the licensed .ttf or .otf font file inside it.
    2. 
      
  2. Open Window → TextMeshPro → Font Asset Creator.
    3. 
      
  3. Assign the imported file as the Source Font File.
    4. 
      
  4. Choose the characters the project needs. ASCII is enough for basic English text; include punctuation, accented characters, symbols, or other languages when the project uses them.
    5. 
      
  5. Use an SDF render mode so the text remains sharp across different sizes.
    6. 
      
  6. Click Generate Font Atlas, inspect the result for missing characters, then click Save.
    7. 
      
  7. Select a TextMeshPro UI object and assign the new asset in its Font Asset field.
    8. 
    


    

      

        
Choose an atlas type

        

          
Static
Best when the set of characters is known, such as menu labels, instructions, subtitles, or fixed dialogue. Only the characters included during generation are available.

          
Dynamic
Adds missing characters to the atlas at runtime and keeps a reference to the source font. Use it when players can enter text or when the required characters are not known in advance.

          
Fallback font
A second Font Asset that TextMesh Pro checks when the primary font does not contain a character. Use fallbacks for additional languages or symbols.

        

      

    

    
Check the font's license before including it in a project. Unity Learn's TextMesh Pro: Font Asset Creation tutorial explains atlas generation, static and dynamic assets, and fallbacks in more detail.

  


  

  

    
Import standalone sprites

    
A standalone sprite is one complete image used as a single UI element, rather than a sprite sheet or an image divided into reusable slices.


    
Core import setup

    
    
      
  1. Select the image in the Project window.
    2. 
      
  2. In the Inspector, set Texture Type to Sprite (2D and UI).
    3. 
      
  3. Leave Sprite Mode set to Single.
    4. 
      
  4. Click Apply.
    5. 
    

  


  

  

    
Display a sprite on the UI

    
Sprites that belong to an interface should be displayed with an Image component inside a Canvas.

    
    
      
  1. In the Hierarchy, right-click and choose UI → Image. Unity creates a Canvas automatically if the scene does not already contain one.
    2. 
      
  2. Select the new Image object.
    3. 
      
  3. Drag the imported sprite into the Image component's Source Image field.
    4. 
      
  4. Use the Rect Transform to position and resize the image within the Canvas.
    5. 
    

    
Use a UI Image for interface elements. A Sprite Renderer belongs in the game world and follows a different rendering and sorting system.

  


  

  

    
Image types

    
The Image component's Image Type controls how the source sprite fills its Rect Transform.


    

      

        

          
Simple
Fits the complete sprite inside the Image object's rectangle. Enable Preserve Aspect to prevent stretching, or click Set Native Size to match the sprite's original pixel dimensions.

          
Filled
Reveals only part of the sprite. Use Fill Method to choose the direction and Fill Amount, from 0 to 1, to control how much is visible. This is useful for health, progress, and loading indicators.

          
Tiled
Repeats a small sprite across the Image object's rectangle. Use it for repeating patterns and interface backgrounds.

        

      

    

  


  

  

    
Draw order

    
Within the same Canvas, Unity draws UI sibling objects in their Hierarchy order. Objects nearer the bottom are drawn later and therefore appear in front of objects above them.


    

      

        

          
Higher in the Hierarchy
Drawn first, so it appears farther back.

          
Lower in the Hierarchy
Drawn later, so it appears in the foreground or on top.

        

      

    


    
Arrange the siblings

    
WRONG: icon is hidden        CORRECT: icon is on top

Canvas                       Canvas
├── Icon                     ├── Background
└── Background               └── Icon

    
Drag objects up or down in the Hierarchy to change their sibling order. For a typical interface panel, place the background first, then place icons, labels, and buttons beneath it.


    
Parenting

    
If an Icon is a child of a Background object, the child is drawn after its parent's Image and appears on top of it. Parenting also makes the Icon move with the Background. The same sibling-order rule still applies between multiple children.

  


  

  

    
Change order with code

    
A script can change a UI object's sibling position at runtime. This is useful for draggable windows, cards, inventory items, or any object that should move to the front when selected.


    
transform.SetAsLastSibling();   // Move to the front
transform.SetAsFirstSibling();  // Move to the back


    

      

        

          
SetAsLastSibling
Moves the GameObject to the bottom of its parent's child list, so it is drawn last and appears in front of its siblings.

          
SetAsFirstSibling
Moves the GameObject to the top of its parent's child list, so it is drawn first and appears behind its siblings.

        

      

    

    
These methods only reorder objects that share the same parent. Separate Canvases can use their own sorting settings, so Canvas order takes priority when UI elements live on different Canvases.
