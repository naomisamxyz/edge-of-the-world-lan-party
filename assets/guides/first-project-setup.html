First Project Setup
Hardware, install, and editor settings before the first Unity project

Hardware Requirements
Check that your personal computer has at least 16 GB of RAM, a modern multicore processor, a graphics card that supports DirectX 11 or Metal, and at least 30 GB of free storage.


Installing Unity
  1. Download and install Unity Hub.
  2. Open Unity Hub and sign in or create a free Unity account.
  3. Open Installs, select Install Editor, and choose Unity 2022.3 LTS.
  4. Check Visual Studio and the build-support modules for Mac, Windows, and WebGL.
  5. When installation finishes, open Projects to create or add a project.
Always use the same Unity version to prevent compatibility problems.


Editor Settings
Under Edit → Project Settings → Editor, configure:
  • Version Control Mode: Visible Meta Files
  • Asset Serialization Mode: Force Text
  • Line Endings for New Scripts: OS Native or Unix
Render Pipeline
Most projects will use the Universal Render Pipeline (URP). Start from Unity’s 3D URP template when possible. For an existing project, install Universal RP through Package Manager, create a URP Pipeline Asset, and assign it under Project Settings → Graphics and Quality.
Resolution
Use 1920 × 1080 with a 16:9 aspect ratio unless the project requires something different. Confirm it under Project Settings → Player → Resolution and Presentation.
Play Mode Tint
Set a noticeable Play Mode tint under Edit → Preferences → Colors so it is clear when the game is running.


Required Packages
Open Window → Package Manager and install only what the project needs:
  • Universal RP
  • Input System
  • Cinemachine
After installing Input System, set Active Input Handling to Input System Package (New) under Project Settings → Player → Other Settings. Restart when prompted.


Layout
Keep the Hierarchy, Scene, Game, Inspector, Project, and Console windows visible. Open Window → Rendering → Lighting, dock the Lighting window, and save the arrangement from the Layout menu.


Initial Test
Create a small test scene with a camera, basic URP lighting, a floor, and an Input Action asset. Confirm rendering, input, physics, Cinemachine, audio, and the selected resolution before building the main project.
Save Scene Changes
Unity does not automatically save scene changes. Save regularly with Ctrl+S on Windows or Command+S on Mac, especially before entering Play Mode, importing packages, or closing Unity. An asterisk beside the scene name indicates unsaved changes.
