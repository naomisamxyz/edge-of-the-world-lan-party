Hardware

    
The Unity editor is demanding. Check your computer against this before installing.


    

    

      

        
Minimum spec

        

          
Memory
at least 16 GB of RAM.

          
Processor
a modern multicore CPU.

          
Graphics
a card that supports DirectX 11 or Metal.

          
Storage
at least 30 GB free.

        

      

    

  


  

  

    
Install Unity

    
Install through Unity Hub, which manages editor versions and your projects.

    
    
      
  1. Download and install Unity Hub.
    2. 
      
  2. Open Unity Hub and sign in, or create a free Unity account.
    3. 
      
  3. Open Installs, choose Install Editor, and select Unity 2022.3 LTS.
    4. 
      
  4. Check Visual Studio and the build-support modules for Mac, Windows, and WebGL.
    5. 
      
  5. When it finishes, open Projects to create or add a project.
    6. 
    

    
Everyone on a project should use the same editor version to avoid compatibility problems.

  


  

  

    
Editor settings

    
Set these once per project so files stay readable in version control and behave the same on every machine.


    

    

      

        
Edit → Project Settings → Editor

        

          
Version Control Mode
Visible Meta Files.

          
Asset Serialization Mode
Force Text.

          
Line Endings for New Scripts
OS Native, or Unix.

        

      


      

        
Also configure

        

          
Render Pipeline
use the Universal Render Pipeline (URP). Start from Unity's 3D URP template when you can; for an existing project, install Universal RP through Package Manager, create a URP Pipeline Asset, and assign it under Project Settings → Graphics and Quality.

          
Resolution
1920 × 1080 at 16:9 unless the project needs something else, under Project Settings → Player → Resolution and Presentation.

          
Play Mode Tint
set a noticeable tint under Edit → Preferences → Colors so it is obvious when the game is running.

        

      

    

  


  

  

    
Packages

    
Open Window → Package Manager and install only what the project needs.


    

    

      

        
For this course

        

          
Universal RP
the render pipeline the projects are built on.

          
Input System
Unity's current input API.

          
Cinemachine
camera rigs and follow cameras.

        

      

    


    
After installing Input System, set Active Input Handling to Input System Package (New) under Project Settings → Player → Other Settings, and restart when prompted.

  


  

  

    
Layout

    
Keep the Hierarchy, Scene, Game, Inspector, Project, and Console windows visible. Open Window → Rendering → Lighting, dock the Lighting window, then save the arrangement from the Layout menu.

  


  

  

    
Initial test

    
Before building the real project, make a small test scene with a camera, basic URP lighting, a floor, and an Input Action asset. Confirm rendering, input, physics, Cinemachine, audio, and the chosen resolution all work.


    

    

      

        
Remember

        

          
Saving
Unity does not save scene changes automatically. Use Ctrl+S / Command+S often — especially before entering Play Mode, importing packages, or closing Unity. An asterisk next to the scene name means unsaved changes.
