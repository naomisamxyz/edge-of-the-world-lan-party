Hardware Requirements

    
Check if your personal computer fulfills these requirements: at least 16 GB of RAM, a modern multicore processor, and a graphics card that supports DirectX 11 or Metal, at least 30 GB of free storage available.

  


  

  

    
Installing Unity

    
    
      
  1. Download and install Unity Hub.
    2. 
      
  2. Open Unity Hub and sign in or create a free Unity account.
    3. 
      
  3. Open Installs, select Install Editor, and choose the Unity 2022.3.62f1 LTS version that we will be using in this class (you might have to go into the archive to find this version). We are all using this version because it runs safely on most computers.
    4. 
      
  4. Check Visual Studio and the build-support module for Mac, Windows and WebGL.
    5. 
      
  5. When installation finishes, open Projects to create or add a project.
    6. 
    

    
Always open a project with the same Unity version that it was created in. Projects can be converted but it is not a safe practice.

  


  

  

    
Unity Account

    
You DO NOT need a subscription to use Unity, you can work under the free license. This can be confusing when creating the account.

  


  

  

    
Creating a Project

    
    
      
  1. In the Unity Hub click on new project and select Editor Version, Project Name, Storage Location and Source Control (more below).
    2. 
      
  2. Always choose a storage location that isn’t connected to a cloud sync. You can use your internal SSD or an external SSD. Never use an HDD external hard drive.
    3. 
      
  3. Pick a template: for this course we will start with 3D (Built-In Render Pipeline) and later move on to working with Universal 3D (you might have to download them first).
    4. 
      
  4. Click Create Project.
    5. 
    

    
The Editor will open and load your project. When loading an empty project and the loading panel freezes or is loading incredibly slow there might be an issue with your storage device or Unity version.

  


  

  

    
Layout

    
Once the Editor has fully loaded you will see Hierarchy, Scene, Game, Inspector and Project windows. On the top right choose Layout 2 by 3. Open Window → Rendering → Lighting and dock the Lighting window on the right with the Inspector. Open Window → General → Console and dock the Console under the Game View on the bottom left. Save the finished arrangement from the Layout menu so it can be restored later.

  


  

  

    
Resolution

    
Set the intended resolution and aspect ratio early. For class projects, use 1920 × 1080 with a 16:9 aspect ratio unless the project requires something different.

    
Add or select this resolution in the Game window and confirm the default window settings under Project Settings → Player → Resolution and Presentation.

  


  

  

    
Play Mode Tint

    
Set a noticeable Play Mode tint under Edit → Preferences → Colors. This makes it clear when the game is running and helps prevent edits that disappear after leaving Play Mode.

  


  

  

    
Initial Test

    
Create a small test scene with a camera, basic lighting, a floor, and a 3D game object with gravity. Confirm that rendering, physics, and the selected resolution work before building the main project.

  


  

  

    
Save Scene Changes

    
Unity does not automatically save scene changes. Save regularly with Ctrl+S on Windows or Command+S on Mac, especially before entering Play Mode, importing packages, or closing Unity. An asterisk beside the scene name indicates unsaved changes.
