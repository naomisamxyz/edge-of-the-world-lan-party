What it is

    
Visual Scripting lets you build behavior by connecting nodes — Unity's built-in blocks for events (“the game starts”, “the player enters a trigger”) and actions (“play a sound”, “destroy this object”) — instead of typing C# code.

    
It's a good starting point if code feels intimidating: the whole flow of logic is laid out where you can see it, and every node is documented right there in the graph. You can always move to code later once a piece of logic outgrows it.

  


  

  

    
Setup

    
    
      
  1. Check whether it's already installed: Edit → Project Settings → Visual Scripting. If that panel doesn't exist yet, install it from Window → Package Manager → Unity Registry → Visual Scripting → Install.
    2. 
      
  2. Select the GameObject that should have behavior, then Add Component → Visual Scripting → Script Machine.
    3. 
      
  3. In the Script Machine component, click New to create a graph asset (reusable across objects), or Embed to keep the graph local to this one object. If dragging a scene object into the graph later doesn't work, switching to Embed is worth trying — a shared graph asset can't always hold a reference to one specific scene object.
    4. 
    

  


  

  

    
Your first graph


    
Show a message on screen for 20 seconds

    
    
      
  1. In the Hierarchy, right-click → UI → Text - TextMeshPro.
    2. 
      
  2. Rename the text object MessageText and type your message into its Text Input field.
    3. 
      
  3. Select the Canvas and add Script Machine.
    4. 
      
  4. Click Edit Graph.
    5. 
      
  5. Add an On Start node.
    6. 
      
  6. Select On Start and enable Coroutine in the Graph Inspector.
    7. 
      
  7. Add Wait For Seconds and set it to 20.
    8. 
      
  8. Drag MessageText from the Hierarchy into the graph to create a reference to it.
    9. 
      
  9. Add Set Active, connect MessageText to its GameObject input, and set Active to false.
    10. 
      
  10. Connect the flow:
        
    On Start → Wait For Seconds (20) → Set Active (false)
    
      
    11. 
    

    
The Canvas stays active. Only MessageText disappears after 20 seconds.


    
React to a trigger

    
    
      
  1. Right-click the graph → Events → Physics → On Trigger Enter.
    2. 
      
  2. Drag out from its output and connect it to an action, such as Destroy or Set Active.
    3. 
      
  3. Make sure the object has a Collider with Is Trigger checked, and that the graph lives on the object that should react.
    4. 
    


    
Once a graph gets long and hard to follow, that's usually the sign to convert that piece of behavior into a short script instead. Visual Scripting is best for small, readable logic, not an entire game's worth of systems.

  


  

  

    
Important nodes

    
These are useful building blocks to search for when creating a graph.


    

    

      

        

          
Start
Run something once when the game starts.

          
Update
Run something or check for something every frame.

          
On Trigger Enter
React when something enters an area.

          
On Collision Enter
React when objects physically collide.

          
Debug Log
Print information in the Console to see what the program is doing.

          
Get Variable
Read stored information.

          
Set Variable
Set or change stored information.

          
Add
Add numbers together.

          
Subtract
Subtract numbers.

          
Multiply
Multiply values.

          
Divide
Divide values.

          
Equal
Check whether two things are the same.

          
Not Equal
Check whether two things are different.

          
Greater Than
Compare numbers.

          
Less Than
Compare numbers.

          
Branch
if: choose what happens based on a condition.

          
And
Check whether two conditions are both true.

          
Or
Check whether at least one condition is true.

          
Not
Reverse true or false.

          
Sequence
Run several actions in order.

          
Wait For Seconds
Delay an action.

          
For Loop
Repeat something a certain number of times.

          
For Each
Do something to every item in a collection.

          
Get Component
Access a component attached to an object.

          
Get Property
Read something from an object or component.

          
Set Property
Change something on an object or component.

          
Get Position
Find an object's position.

          
Set Position
Change an object's position.

          
Instantiate
Create an object.

          
Destroy
Remove an object.
