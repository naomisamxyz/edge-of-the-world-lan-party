First script

    
A Unity script is a C# class that Unity runs on an object in the scene. This one reads the keyboard every frame and moves whatever object it is attached to. Make a file named MoveObject.cs and paste this in:


    


      

        

          
          
          
          
        

        


using UnityEngine;

public class MoveObject : MonoBehaviour
{
    public float speed = 3f;

    void Update()
    {
        float x = Input.GetAxis("Horizontal");

        float z = Input.GetAxis("Vertical");

        Vector3 movement = new Vector3(x, 0f, z);

        transform.Translate(movement * speed * Time.deltaTime);
    }
}

        

      


      


        

          IMPORT
          
using UnityEngine; pulls in the Unity types this script needs — MonoBehaviour, Vector3, Input, Time. Almost every script starts with this line.

        


        

          THE CLASS
          
Everything from public class down to the last } is the class body. The name must match the file name exactly — MoveObject.cs — and : MonoBehaviour is what lets you drop it onto a GameObject.

        


        

          INSPECTOR FIELD
          
A public field turns into an editable slot in the Inspector. You can change speed there, even while the game is running, without touching the code.

        


        

          UPDATE( ) — RUNS EVERY FRAME
          
Update() and everything between its braces runs once per frame. It reads the arrow / WASD keys with Input.GetAxis (−1 to 1), packs them into a Vector3 direction with Y left at 0, and moves the object with transform.Translate. Multiplying by Time.deltaTime keeps the speed the same at any frame rate.

        


      


      


    


    
The full explanation of every line is in the next section.

  


  

  

    
First script with comments

    
The same script again, with every line explained in a comment. You do not need to keep the comments in your own file — they are here to read once.


    

      

        


// Gives this script access to Unity features such as
// MonoBehaviour, Vector3, Transform, Input, and Time.
using UnityEngine;

// A class is a container that groups related information
// and instructions together.
//
// "MoveObject" is simply the name we chose for this class.
// The script file must also be named "MoveObject.cs".
//
// ": MonoBehaviour" allows this class to work as a Unity component.
// This means the script can be attached to a GameObject and use
// Unity methods such as Update().
public class MoveObject : MonoBehaviour
{
    // A variable is a named place where the program stores a value.
    //
    // "public" makes this variable visible and editable in
    // Unity's Inspector.
    //
    // "float" means this variable stores a number that can
    // include decimal places.
    //
    // "speed" is the name we chose for the variable.
    //
    // "= 3f" gives speed a starting value of 3.
    // The "f" tells C# that the number is a float.
    public float speed = 3f;

    // Unity automatically calls Update() once every frame.
    //
    // We check the keyboard inside Update so Unity responds
    // continuously while the player presses or releases a key.
    void Update()
    {
        // Creates a float variable named "x".
        //
        // Input.GetAxis("Horizontal") checks Unity's horizontal input:
        // - A or left arrow produces a negative value.
        // - D or right arrow produces a positive value.
        // - No input produces a value near zero.
        //
        // Unity gradually changes the value between -1 and 1,
        // which makes starting and stopping feel smoother.
        float x = Input.GetAxis("Horizontal");

        // Creates a float variable named "z".
        //
        // Input.GetAxis("Vertical") checks Unity's vertical input:
        // - S or down arrow produces a negative value.
        // - W or up arrow produces a positive value.
        // - No input produces a value near zero.
        //
        // This axis is called "Vertical" in Unity's input settings,
        // but here we use it for movement along the 3D Z axis.
        float z = Input.GetAxis("Vertical");

        // Vector3 stores three numbers: X, Y, and Z.
        //
        // Here we create a Vector3 variable named "movement":
        // - x controls left and right.
        // - 0f means this script does not move the object up or down.
        // - z controls forward and backward.
        //
        // Examples:
        // W creates approximately (0, 0, 1).
        // A creates approximately (-1, 0, 0).
        Vector3 movement = new Vector3(x, 0f, z);

        // Every GameObject has a Transform component.
        //
        // A Transform stores and controls the object's:
        // - position: where the object is
        // - rotation: which direction it faces
        // - scale: how large or small it is
        //
        // The lowercase word "transform" refers to the Transform
        // belonging to the GameObject carrying this script.
        //
        // Translate changes the object's position using "movement".
        //
        // Multiplying by "speed" controls how fast the object moves.
        //
        // Multiplying by Time.deltaTime accounts for the amount of
        // time since the previous frame. This keeps the object's speed
        // approximately consistent across different frame rates.
        //
        // Translate uses the object's local directions by default.
        // Therefore, forward follows the direction the object is facing.
        transform.Translate(movement * speed * Time.deltaTime);
    }
}

        

      

    

  


  

  

    
Attaching it to an object

    
A script does nothing on its own. It runs only once it is a component on a GameObject.

    
    
      
  1. Put a cube or a model in the scene.
    2. 
      
  2. Drag MoveObject.cs from the Project window onto that object — or select the object and use Add Component in the Inspector.
    3. 
      
  3. The Speed field now shows in the Inspector. Adjust it there, even while the game is running, to feel the difference.
    4. 
      
  4. Press Play and use the arrow keys or WASD.
    5. 
    

  


  

  

    
Adding physics

    
On its own, Translate slides the object straight through walls and floors and ignores gravity. To make it collide and fall, add a physics body and colliders.


    

    

      

        
The object also needs

        

          
Rigidbody
with Use Gravity on — makes the object fall and respond to collisions.

          
Collider
on the object, and one on anything it should be able to stand on.

          
Constraints
on the Rigidbody, freeze Rotation X and Rotation Z so the object does not tip over.

          
Terrain Collider
if the ground is Unity terrain rather than a mesh.

        

      

    


    
Translate moves along the object's own axes by default, so "forward" follows the direction the object is facing.

  


  

  

    
Second script

    
A shorter way to write the same movement, for an object that already has a Rigidbody. The three axis values go straight into Translate instead of through a named Vector3, and the middle value is 0 so the Rigidbody's gravity handles vertical movement. Name this file Move.cs.


    

      

        


using UnityEngine;

public class Move : MonoBehaviour
{
    public float speed = 5f;

    void Update()
    {
        float x = Input.GetAxis("Horizontal");
        float z = Input.GetAxis("Vertical");

        transform.Translate(x * speed * Time.deltaTime, 0, z * speed * Time.deltaTime);
    }
}

        

      

    

  


  

  

    
Second script with comments

    
The second script, explained line by line.


    

      

        


// Gives the script access to Unity features.
using UnityEngine;

// A class is a container for related variables and instructions.
//
// "Move" is simply the name we chose for the class.
// Because the class is named Move, the file must be named "Move.cs".
//
// MonoBehaviour allows this script to be attached to a GameObject.
public class Move : MonoBehaviour
{
    // A variable is a named place where we store information.
    //
    // "public" makes this variable visible in Unity's Inspector,
    // allowing us to change it without editing the script.
    //
    // "float" means this variable stores a number that can have decimals.
    //
    // "speed" is the name we chose for this variable.
    //
    // "= 5f" gives speed a starting value of 5.
    public float speed = 5f;

    // Unity automatically runs Update once every frame.
    //
    // We use Update because the script needs to check the player's
    // keyboard input continuously while the game is running.
    void Update()
    {
        // Creates a float variable named "x".
        //
        // GetAxis("Horizontal") checks for horizontal movement input.
        // The A and left-arrow keys produce a negative number.
        // The D and right-arrow keys produce a positive number.
        // When no horizontal key is pressed, the value moves toward zero.
        float x = Input.GetAxis("Horizontal");

        // Creates a float variable named "z".
        //
        // GetAxis("Vertical") checks for forward and backward input.
        // The S and down-arrow keys produce a negative number.
        // The W and up-arrow keys produce a positive number.
        // When no vertical key is pressed, the value moves toward zero.
        float z = Input.GetAxis("Vertical");

        // Every GameObject has a Transform component.
        //
        // The Transform stores the object's position, rotation, and scale.
        // The lowercase word "transform" gives this script access to the
        // Transform belonging to the GameObject carrying this script.
        //
        // Translate changes the object's position:
        //
        // x * speed * Time.deltaTime controls left-and-right movement.
        //
        // The middle value is 0, so this script does not directly move
        // the object upward or downward. The Rigidbody's gravity handles
        // its vertical movement.
        //
        // z * speed * Time.deltaTime controls forward-and-backward movement.
        //
        // Time.deltaTime is the amount of time since the previous frame.
        // Multiplying by it makes movement approximately the same speed
        // on computers with different frame rates.
        //
        // By default, Translate moves along the object's local directions.
        // If the object is rotated, its forward direction rotates with it.
        transform.Translate(
            x * speed * Time.deltaTime,
            0,
            z * speed * Time.deltaTime
        );
    }
}
